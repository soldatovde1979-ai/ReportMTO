## Порядок

**Шаг 0. Разово выключить уровни конфиденциальности.** Excel → Данные → Получить данные →
Параметры запроса → Глобальные → Конфиденциальность → «Всегда пропускать параметры уровня
конфиденциальности». Без этого шага остальное можно не проверять: Formula Firewall
отклонит обновление независимо от кода. Настройка глобальная, задаётся один раз.

**Шаг 1.** Скопировать файлы поверх одноимённых в репозитории. Имена совпадают с
существующими, сборочный скрипт подхватит их без правок.

**Шаг 2.** `prmSourcePath` в вашей книге сейчас — обычный запрос, а не параметр. Сборочный
скрипт его намеренно не трогает (это рабочее состояние с путём к JSON). Есть два пути:

- **проще:** ничего не делать. Первое же нажатие «Загрузить» после обновления модулей
  перезапишет его вместе с meta-записью параметра — новый `modMain` пишет её всегда;
- **чище:** удалить `prmSourcePath` в панели «Запросы и подключения» до сборки, тогда
  скрипт создаст его сразу параметром.

**Шаг 3.** Запустить сборку:

```powershell
.\tools_Build-ReportMTO.ps1 -ProjectRoot "C:\путь\к\ВашаПапкаПроекта"
```

Скрипт создаст `qExistingData` и обновит текст всех изменившихся запросов.

**Шаг 4.** Открыть `qExistingData` в панели запросов → Закрыть и загрузить в... →
**Только создать подключение**. На лист его грузить нельзя.

**Шаг 5.** Alt+F11 → Debug → Compile VBAProject. Должно пройти молча.

**Шаг 6.** Загрузить `tests/test_sppr_tablet_v1.json` и сверить с `tests/ОЖИДАЕМОЕ_v1.md`.
Тестовый файл маленький — если что-то не так, видно сразу и без ожидания 132 тысяч строк.

**Шаг 7.** Только после этого — реальная выгрузка.

## Если загрузка всё равно падает

Не гадать по тексту `MsgBox`. Создать пустой запрос `qDiagImport`, вставить в него
`src/powerquery/qDiagImport.pq`, загрузить как «Только создать подключение», открыть на
изменение и пройти по шагам сверху вниз. Первый шаг с ошибкой вместо данных и есть место
поломки. Инструкция — в шапке самого файла.

Итоговая таблица `qDiagImport` отвечает разом на семь вопросов: сколько записей в файле,
все ли поля попали в выборку, как РЕАЛЬНО пишется `ready_for`, сколько дат не разбирается,
какого типа приходит `in_bounds`, есть ли дубли `Key` внутри файла.
