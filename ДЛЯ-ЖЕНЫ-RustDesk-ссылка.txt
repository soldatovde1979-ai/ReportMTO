RustDesk — удалённый доступ к этому компьютеру
=============================================

Ссылка для скачивания (скопировать в браузер):

https://github.com/rustdesk/rustdesk/releases/download/1.4.9/rustdesk-1.4.9-x86_64.exe

Это официальный сайт разработчика (github.com/rustdesk). Файл около 23 МБ.


Шаг 1. Запустить
----------------
Запустить скачанный файл rustdesk-1.4.9-x86_64.exe.


Шаг 2. Постоянный пароль — он задаётся НА ГЛАВНОМ ЭКРАНЕ, не в настройках
-------------------------------------------------------------------------
В левой части окна есть блок "Ваш рабочий стол", в нём:

    ID:      123 456 789
    Пароль:  ******        <- рядом кнопка с ТРЕМЯ ТОЧКАМИ

Нажать кнопку с тремя точками справа от пароля
   -> выбрать "Установить постоянный пароль"
   -> придумать пароль, ввести два раза, сохранить.

Без этого шага для каждого подключения нужен человек за компьютером,
который нажмёт "Принять" — то есть смысл теряется.


Шаг 3. Автозапуск
-----------------
Значок шестерёнки (настройки) -> раздел "Основные" -> отметить пункты
про запуск вместе с Windows.

Если программу устанавливали обычным способом (а не запускали как
переносную), она уже прописана службой и стартует сама — тогда этот
шаг можно пропустить.


Шаг 4. Передать Дмитрию
-----------------------
   - ID (девять цифр с главного экрана)
   - постоянный пароль, который задали

Всё. Больше ничего нажимать не надо.

Если каких-то пунктов на экране нет — сфотографировать главное окно
и отправить Дмитрию: в разных версиях подписи немного отличаются.
