Столбцы: Дирекция / ARM → Нед. 15, Нед. 17, Нед. 23, … Нед. 30 → Всего.
Строки (в постановке порядок ДГМ → ДЭНТ, у вас в описании ДЭНТ → ДГМ):
ДГМ: всего → ПЛАНШЕТ → ПК → % планшет;
ДЭНТ: всего → ПЛАНШЕТ → ПК → % планшет.
Фильтрация: только последние 8 недель по дате счёт-фактуры; in_bounds = истина; «ARM = не подписан — исключаем».
Значения: Count строк по соответствию arm/дирекции; % планшет = ПЛАНШЕТ / (ПЛАНШЕТ + ПК) * 100.
Оформление: цветовая подсветка строки % планшет — «чем больше число тем зеленее, чем меньше краснее, посередине жёлтый» (реализовано в проекте шкалой #ef4444 → #f59e0b → #10b981).

Подтверждение по «Всего %»: строки «Всего» (сумма по неделям) в постановке есть, а отдельной строки «Всего %» (сводный % по обеим дирекциям) в постановке действительно нет.

Где это реализовано и зафиксировано в проекте:
modContentMTO.bas — BuildBlock1Table (строка «% планшет» по каждой неделе дирекции), позднее BuildWeeksTable (строки: всего → % → ПЛАНШЕТ → ПК, столбцы — недели окна WEEKS_WINDOW);
ТЗ-документы: tz_Report v1.2.md и MTO_Презентация_и_блоки_данных_v2.5.md.
