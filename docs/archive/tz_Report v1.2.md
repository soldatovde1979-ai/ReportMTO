# ТЗ на доработку формирования отчёта МТО — v1.2

**Исполнитель:** кодинг-агент (DeepSeek Pro, Zoo Code / VS Code), работает с файлами репозитория.
**Заказчик требований:** `MTO_Презентация_и_блоки_данных_v2.2.md` — при расхождении верен он.
**Объём:** переход презентации с 6 реализованных слайдов на 4 целевых, новые блоки данных,
встраивание шрифтов, перевод раскраски «% планшет» на рамку.

**Период данных на стенде:** `date` от `46023` до `46273,4812` (Excel-serial) —
**01.01.2026 00:00 … 08.09.2026 11:32**, 250 дней ≈ 36 недель.

## 0. Контекст, который нельзя нарушать

Среда: единственный файл `ReportMTO.xlsm` во внутреннем контуре. Power Query (M) + VBA + HTML.
Готовый отчёт — **автономный офлайн-HTML** в `result\`.

### 0.1 Жёсткие запреты

| № | Запрет | Почему |
|---|---|---|
| 1 | Любая внешняя ссылка в готовом HTML (`<link href="http…">`, `<script src="http…">`, CDN, Google Fonts, Chart.js) | отчёт открывается на машинах без интернета — ссылка тихо деградирует в системный шрифт и ломает вёрстку |
| 2 | Импорт и дедупликация построчным VBA | контракт: только Power Query |
| 3 | `References` для HTTP | только `CreateObject` (позднее связывание) |
| 4 | ФИО (`employee`) и `defect_desc` в промпт к внешнему ИИ | 152-ФЗ; в промпт уходят только псевдонимы «Сотрудник N» |
| 5 | Хардкод провайдера / модели / URL / порогов | только лист `Variable` |
| 6 | Любые расчёты, прогнозы и суждения о людях на стороне ИИ | ИИ интерпретирует готовые числа, считает VBA/PQ |
| 7 | Почта, Google Диск, любая внешняя доставка | результат сохраняется в `result\` и всё |

### 0.2 Правка Core

Core-модули: `modMain`, `modPQSync`, `modAIGateway`, `modHTMLEngine`, `modPivotBuilder`,
`modAggregate`, `modColor`, `modLog`.

**Критерий:** правка Core допустима, только если та же правка понадобилась бы второму отчёту
на этой платформе. Специфика МТО — расширяй `modContentMTO`, Core не трогай.

В этом ТЗ Core правится **ровно один раз** — задача T2 (`GroupPercentile` в `modAggregate`).
Обоснование внутри задачи. Все остальные задачи — `modContentMTO`, `tmp_index.html`, `.pq`, `Variable`.

Если по ходу работы кажется, что нужна ещё одна правка Core — **остановись и спроси**, не делай.

### 0.3 Версионирование и выдача

- Модули VBA и M: версия комментарием в первых строках файла, новая запись **сверху**, старые
  не затирать. Формат: `' Версия 7.0 от 09.09.2026 Переход на 4 слайда, новые блоки`.
- Выдача правок VBA: изменённая процедура целиком. Больше трёх правок или меняется состав
  процедур — модуль целиком, файлом.
- Выдача M: запрос целиком, не фрагментом.
- К каждой правке — одна строка «что изменено и почему».

## T1. Power Query — новые вычисляемые поля

**Файл:** `src\powerquery\fnNormalizeFields.pq`. Контракт функции остаётся `(table) as table`,
менять сигнатуру запрещено.

Добавить три поля после существующих `postN` и `yearWeek`:

| Поле | Тип | Формула | Зачем |
|---|---|---|---|
| `dateWeek` | `Int64.Type` | `Date.Year([date]) * 100 + Date.WeekOfYear([date], Day.Monday)` | ось времени для неподписанных: у них `status_date` пуст, а `yearWeek = 101` |
| `dateMonth` | `Int64.Type` | `Date.Year([date]) * 100 + Date.Month([date])` | помесячная ось |
| `isSigned` | `type logical` | `[arm] <> null and [arm] <> "" and [arm] <> "НЕ ПОДПИСАНО"` | признак подписанного события, чтобы не повторять условие в каждом блоке |

Требования:
- поля добавляются **только если исходное поле присутствует** в наборе колонок (как уже сделано
  для `TypeSpec` через `List.Select` — 1С опускает поля со значением `null`);
- `try … otherwise null` вокруг преобразований дат: `date` может прийти пустой;
- неделя считается от понедельника (`Day.Monday`) — иначе разъедется с `week_status` из 1С.

> **Разработчику:** в текущем коде (`fnNormalizeFields.pq` v6) у неподписанных строк `yearWeek` = null
> (поля `*_status` вычисляются из `status_date`), а не 101 — на «101» не опираться. `date` тоже может
> быть null (терпимое приведение v5) → `dateWeek`/`dateMonth` тогда null.

**Приёмка T1:** после обновления запроса в `tbDATA` присутствуют три новые колонки; у строк
с `arm = "НЕ ПОДПИСАНО"` поле `dateWeek` заполнено (не `101`), `isSigned = FALSE`.

## T2. Core — перцентили в `modAggregate`

**Единственная правка Core в этом ТЗ.** Обоснование, почему она допустима: среднее по `deltaHours`
перекошено хвостом (8,28 ч против медианы 0,73 ч, максимум 13 791 ч). Медиана и p90/p99 —
это общая потребность любой отчётности на этой платформе, а не специфика МТО; `modAggregate` уже
содержит `GroupCount` / `GroupCountDistinct` / `GroupAverage`, перцентиль — соседний примитив
того же ряда.

```vba
' Возвращает Dictionary: ключ группировки (значения через "|" с завершающим разделителем)
'                        -> значение перцентиля p (0..1) по числовому столбцу valueCol.
' Пустые/нечисловые значения valueCol в выборку не попадают.
' Метод: линейная интерполяция между соседними элементами отсортированного ряда
'        (тот же метод, что EXCEL.PERCENTILE.INC), чтобы числа сходились с ручной проверкой в книге.
' Если после фильтрации в группе нет ни одного значения — группа в результат не включается.
Public Function GroupPercentile(ByVal groupCols As Variant, _
                                ByVal valueCol As String, _
                                ByVal p As Double, _
                                Optional ByVal filters As Variant) As Object
```

Дополнительно — вспомогательная публичная функция для одного значения без группировки:

```vba
' Перцентиль по всему отфильтрованному набору, без группировки. Возвращает Double.
' При отсутствии значений возвращает 0 и выставляет ByRef-флаг hasValue = False.
Public Function Percentile(ByVal valueCol As String, _
                           ByVal p As Double, _
                           Optional ByVal filters As Variant, _
                           Optional ByRef hasValue As Boolean) As Double
```

Требования:
- работает по тому же снимку `DataBodyRange.Value2` и той же карте колонок, что остальные функции
  модуля — новых обходов листа не заводить;
- формат ключей словаря — как у `GroupCount`: `"ДГМ|202643|"`;
- сортировка ряда — собственная реализация (QuickSort или сортировка вставками), без `Application.WorksheetFunction`;
- `p` вне диапазона 0…1 → `Err.Raise` с внятным текстом.

**Приёмка T2:** на выгрузке 25 000 записей `Percentile("deltaHours", 0.5, FBase())` даёт
**0,73 ч ± 0,01**, `p = 0.9` → **7,7 ч ± 0,1**. Если не сходится — сначала проверь, что берутся
только строки со статусом «Готов к выбытию» (у «Готов к приемке» `deltaHours` всегда `null`).

### T3.1 Отчётная неделя

```vba
' Отчётная неделя: Variable/REPORT/WEEK.
' Пусто или 0 -> авто: максимальный yearWeek в данных минус одна неделя.
' Явное число N (1..53) -> yearWeek текущего года данных с номером недели N.
Private Function GetReportWeek() As Long

' Список yearWeek окна: WEEKS_WINDOW недель назад от отчётной, по возрастанию.
' Пропуски (недели без данных) сохраняются как колонки со значением "—".

```

Переход через границу года выполнять арифметикой по `yearWeek` (`гггг*100+нн`), а не вычитанием 1
из числа: неделя 202601 − 1 ≠ 202600.

> **Разработчику:** «минус одна неделя» в авто-режиме — это предыдущий по списку присутствующих
> `yearWeek` (текущая `ReportWeekValue()` делает именно так), а не `yearWeek − 1`: при пропуске недели
> арифметика даст несуществующую неделю. `GetWeekWindow` — только недели, реально присутствующие
> в данных (`rules.md`).

Ни одной внешней библиотеки. Три функции, все — чистая генерация SVG-строки:

' highlightIdx — индекс строки, которую красить критическим цветом (-1 = нет).

Обязательные требования к SVG:

  (`svg{display:block;width:100%;height:auto}` уже есть в шаблоне);
- атрибут `role="img"` и `aria-label` с осмысленным текстом;
- деление на ноль: пустой набор значений → вернуть `<div class="empty-note">Нет данных</div>`.

Семь плиток за отчётную неделю, каждая — дельта к ПН-1 и спарклайн за окно недель:

| Плитка | Расчёт |
|---|---|
| Нарядов открыто | `GroupCountDistinct("number")`, фильтр `date` ∈ ПН |
| Закрыто нарядов | то же, `ready_for = Готов к выбытию`, `status_date` ∈ ПН |
| Висит на конец недели | накопительно открыто − накопительно закрыто на конец ПН |
| Медиана в ремзоне | `Percentile("deltaHours", 0.5)`, формат «чч:мм» |
| Без поста ремзоны | нарядов с пустым `post` за ПН + доля |
| % планшета | `ПЛАНШЕТ / (ПЛАНШЕТ + ПК)` по событиям ПН, дельта в **п.п.** |
| Не подписано | событий `arm = НЕ ПОДПИСАНО` за ПН + доля |

> **Разработчику (формула «Висит на конец недели» в постановке не расписана — принято):**
> открыто накопительно = `Count(Distinct number)` с `date` ≤ конец ПН; закрыто накопительно — то же
> с `ready_for = Готов к выбытию` (нормализован) и `status_date` ≤ конец ПН; конец ПН = воскресенье
> отчётной недели. При расхождении чисел с ручной проверкой — вернуться к формуле.

Плитки «Заездов техники», «Материалы за неделю», «Готово, но не забрано» **не реализуются** —
полей нет в выгрузке. Заглушек не ставить.

### T8.3 Встраивание шрифтов

Причина: на макете помечено «шрифт не совпадает». `<link>` на Google Fonts в офлайн-отчёте
не загрузится, системная подстановка ломает типографику.

Пять начертаний: **Oswald 500, 600**, **IBM Plex Sans 400, 600**, **IBM Plex Mono 400**.
Латиница + кириллица. Лицензия обоих семейств — SIL OFL 1.1, встраивание разрешено.

Процедура (выполняется один раз на машине разработчика, где есть интернет):

```bash
# 1. получить woff2 нужных начертаний (с fonts.google.com или из репозиториев проектов)
# 2. подрезать до кириллицы+латиницы, чтобы не тащить лишние 200 КБ
pip install fonttools brotli
pyftsubset Oswald-Medium.ttf \
  --unicodes="U+0000-00FF,U+0400-045F,U+2010-2027,U+20BD,U+2116" \
  --layout-features="kern,liga" --flavor=woff2 --output-file=oswald-500.woff2
# 3. закодировать
base64 -w0 oswald-500.woff2 > oswald-500.b64
```

Вставка в `<style>`:

```css
@font-face{
  font-family:"Oswald";font-style:normal;font-weight:500;font-display:swap;
  src:url(data:font/woff2;base64,<…>) format("woff2");
}
/* ещё 4 таких блока */
```

Требования:
- `font-display:swap`;
- fallback-цепочки сохраняются: `font-family:"IBM Plex Sans","Segoe UI",system-ui,sans-serif`;
- ни одного `http`-URL в файле после сборки. Проверка: `grep -c "https\?://" tmp_index.html`
  должен вернуть `0`;
- вес шаблона после встраивания фиксируется в комментарии в начале файла. Ориентир — 200–350 КБ;
  если вышло существенно больше, значит подмножество не подрезано.

> **Разработчику:** в репозитории шрифтов Oswald/IBM Plex нет — `tools/fonts` содержит только
> Segoe UI/Consolas. Сначала получить woff2 (машина с интернетом) и положить в `tools/fonts`,
> затем встраивать. `tools/make_fonts_woff2.py` рассчитан на системные шрифты — для Oswald/IBM Plex
> нужны свои исходники и `pyftsubset` (см. выше).
