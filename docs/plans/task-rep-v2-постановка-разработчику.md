## 3. Контекст: текущая архитектура (проверено по коду 14.09.2026)

**Слайд 1 — [`modContentZone.bas`](../src/vba/modContentZone.bas:3071).** Словарь плейсхолдеров заполняется в `FillZonePlaceholders`:
`BLOCK_HANG_ZNTYPE` ← [`BuildHangByZnType()`](../src/vba/modContentZone.bas:3523), `BLOCK_HANG_STATUS` ← [`BuildHangByStatus()`](../src/vba/modContentZone.bas:3563), `BLOCK_FLOW_ZNTYPE` ← [`BuildFlowZnType()`](../src/vba/modContentZone.bas:3602), `BLOCK_FLOW_DEFEKT` ← [`BuildFlowDefekt()`](../src/vba/modContentZone.bas:3633), `BLOCK_NOPOST_WEEKLY` ← [`BuildNoPostWeekly()`](../src/vba/modContentZone.bas:3656). Запись наряда `mZn` хранит: `Z_WEEK` (неделя), `Z_TYPE` (`zn_type`), `Z_TEK` (`TekStatusPoDoc`), `Z_POST` (`post`), `Z_DEFEKT` (`defekt_type`), `Z_DATE`, `Z_CLOSED`, `Z_SIGNED`. Отчётная неделя — `ZoneReportWeek()`.

**Слайды 2/3 — [`modContentDisc.bas`](../src/vba/modContentDisc.bas:752).** `FillDiscPlaceholders` заполняет:
`BLOCK_WEEKS_*` ← [`BuildWeeksTable()`](../src/vba/modContentDisc.bas:225) (матрица % планшета по ремзонам × недели окна), `BLOCK_POSTS_*` ← [`BuildPostsTable()`](../src/vba/modContentDisc.bas:305) (площадки за отчётную неделю), `BLOCK_PEOPLE_*` ← [`BuildPeople()`](../src/vba/modContentDisc.bas:370) (сотрудники, ПН-3…ПН), `BLOCK_SIGNSTAT_*` ← [`BuildSignStat()`](../src/vba/modContentDisc.bas:478) (разбор подписей наряда). Запись наряда `mOrd` (поля `E_*`, [`modContentDisc.bas:27`](../src/vba/modContentDisc.bas:27)): дата, `post`, `postN`, `owner_dep`, `zn_type`, АРМ-подписи 4 статусов, их даты. `TekStatusPoDoc` в `mOrd` пока **не читается** — для таблиц 5/6 его нужно добавить в `EnsureDisc` (с проверкой `HasColumn("TekStatusPoDoc")`, по аналогии с [`modContentZone.bas:188`](../src/vba/modContentZone.bas:188)).

**Слайд 4 — [`modContentDisc.bas`](../src/vba/modContentDisc.bas:599).** `KPI_UNSIGNED`, `BLOCK_UNSIGNED_AGE/POST/OWNER/ZNTYPE`. Счётчик «наряд без единой подписи» — `SignedCount(e)=0`.

**Шаблон.** Слайды 1–4 свёрстаны в [`tmp_index.html`](../tmp_index.html:221) (одна длинная строка, правки точечные). Секции слайда 1: (1) KPI, (2) «two-col» Д1/Д2 (`BLOCK_HANG_ZNTYPE` / `BLOCK_HANG_STATUS`), (3) «two-col» Б3/Б2 (`BLOCK_FLOW_DEFEKT` / `BLOCK_FLOW_ZNTYPE`). Заголовок блока Д2 в шаблоне: `Текущий статус заказ-наряда · TekStatusPoDoc`. Слайды 2/3 содержат плейсхолдеры `BLOCK_WEEKS_*`, `BLOCK_POSTS_*`, `BLOCK_PEOPLE_*`, `BLOCK_SIGNSTAT_*` (+`_DENT`/`_DGM`).

## 4. Задачи

### Часть 1

**А1 (п. 22). Б3 «Какие дефекты были за неделю».** [`BuildFlowDefekt()`](../src/vba/modContentZone.bas:3633) считает по всему `mZn` без фильтра недели.
- Вход: `mZn`. Выход: HBars топ-10 + NoteBlk (как сейчас).
- Изменение: фильтр `Z_WEEK = ZoneReportWeek()`; NoteBlk переформулировать с «на весь массив» на «за отчётную неделю <WLab(rw)>» (без суждений — см. Б1).
- Файл: [`modContentZone.bas`](../src/vba/modContentZone.bas:3633).

**А2 (п. 24). Б4 «Без поста ремзоны».** Данные уже готовы: `BLOCK_NOPOST_WEEKLY` заполняется ([`modContentZone.bas:3074`](../src/vba/modContentZone.bas:3074)), но плейсхолдера в шаблоне нет.
- Изменение: в [`tmp_index.html`](../tmp_index.html:221) добавить секцию с `mock-label` «Без поста ремзоны» и `{{BLOCK_NOPOST_WEEKLY}}` после секции Б3/Б2 слайда 1; зеркально в [`build/tmp_index.html`](../build/tmp_index.html:221).
- Файлы: оба шаблона.

### Часть 2

**Б1 (п. 1). Ревизия комментариев.** Во всех NoteBlk/`calc-note` таблиц и графиков отчёта убрать суждения; комментарий должен описывать: показываемые поля, алгоритм сбора, период. Затрагивает слайд 1 и слайды 5–8 в [`modContentZone.bas`](../src/vba/modContentZone.bas:1), слайды 2–4 в [`modContentDisc.bas`](../src/vba/modContentDisc.bas:1). Выход: тексты без оценочных суждений, с полями/алгоритмом/периодом.

**Б2 (п. 2).** В шаблоне заголовок блока Д2 `Текущий статус заказ-наряда · TekStatusPoDoc` → `Текущий статус заказ-наряда` (оба файла шаблона).

**Б3 (п. 3). Новые блоки слайда 1** после Д1/Д2, в порядке постановки:
- «Без ремзоны по видам воздействия» — выборка: наряды с пустым `postN`; разрез `Z_TYPE` (`zn_type`); таблица «Вид воздействия / ЗН / %».
- «Без ремзоны по статусу ЗН» — та же выборка; разрез `Z_TEK` (`TekStatusPoDoc`); таблица «Статус ЗН / ЗН / %».
- Вход: `mZn`. Выход: таблицы, как в `BuildHangByZnType`/`BuildHangByStatus`. Единица счёта — заказ-наряд.
- Изменения: новые публичные функции в [`modContentZone.bas`](../src/vba/modContentZone.bas:3601), записи в словарь `FillZonePlaceholders`, новые плейсхолдеры (имена — на усмотрение разработчика, зафиксировать в постановке по факту) в обоих шаблонах.

**Б4 (п. 4). Ответ о возвратах.** Внести в [`docs/task-rep-v2.md:111`](../task-rep-v2.md:111) текст R4 и отметить задачу `[x]`. Код не менять.

**Б5 (п. 5). Таблица 1 слайда 2 (только ДЭНТ).**
- Вход: `tbDATA`. Выход: таблица на слайде 2 (ДЭНТ).
- Строки: Всего → ПЛАНШЕТ → ПК → % планшет.
- Столбцы: недели окна 8 по убыванию (по `status_date`) → Всего.
- Фильтры: `postN ∈ {СТК, ПРК}` (существующий механизм нормализации списка `СТК+ПРК` → `;` см. [`docs/plans/tz_Reports2.md`](../plans/tz_Reports2.md:84)); `arm ∈ {ПК, ПЛАНШЕТ}` («НЕ ПОДПИСАНО» исключается); 8 недель по `status_date` (R1); `in_bounds` не фильтруется (R2).
- Значения: Count строк по arm/дирекции; % планшет = ПЛАНШЕТ / (ПЛАНШЕТ + ПК) × 100.
- Оформление: подсветка строки % планшет по шкале `#ef4444` (меньше) → `#f59e0b` (середина) → `#10b981` (больше); интерполяция — [`modColor.InterpolateHex()`](../src/vba/modColor.bas:1).
- Реализация: в [`modContentDisc.bas`](../src/vba/modContentDisc.bas:1) + плейсхолдер + оба шаблона.

**Б6 (п. 6). Таблица 2.** Доработать [`BuildPostsTable()`](../src/vba/modContentDisc.bas:305):
- Разрез строк: `postN` (R3) — «Пост не указан» отдельной строкой.
- Столбцы строго по постановке: РемЗона / Нарядов / С планшета / % планшетов (колонка «Оценка» исключается).
- Итоговая строка «Всего» первой строкой: всего нарядов, из них с планшета, общий % планшета.
- Отбор — отчётная неделя, единица счёта — заказ-наряд (как сейчас).
- Строки — все ремзоны, по которым за неделю есть оформленные ЗН.
