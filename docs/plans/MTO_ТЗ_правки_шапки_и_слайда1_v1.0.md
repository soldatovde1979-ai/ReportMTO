## Задача 1. Шапка — [`src/vba/modContentMTO.bas`](../../src/vba/modContentMTO.bas)

### 1.1 Заголовок и подзаголовок

- [`BuildPlaceholders()`](../../src/vba/modContentMTO.bas:4075): `REPORT_TITLE` заменить с «Отчёт МТО»
  на **«Исполнительская дисциплина инженеров ДЭНТ и ДГМ»**.
- [`BuildLede()`](../../src/vba/modContentMTO.bas:4141) переписать на:
  **«Отчет о состоянии техники за {неделя} — с {дата начала} по {дата конца}»**, где:
  - `{неделя}` — `modContentZone.WLab(rw)`, например `2026-36`;
  - `{дата начала}` — понедельник отчётной недели `modContentZone.WeekMonday(rw)`;
  - `{дата конца}` — `WeekMonday(rw) + 6` (воскресенье);
  - формат дат — `dd.mm.yyyy` (`Format$(..., "dd.mm.yyyy")`).
- Каждое из трёх значений-плейсхолдеров оборачивается в `<span class="hl">…</span>` —
  **белый жирный** по постановке. Разделители и слова периода — обычным текстом.
- `eyebrow` шапки не трогать. Старый текст про «Восемь слайдов…» убирается целиком.

### 1.2 Факты шапки «С начала года»

[`BuildFactsRef()`](../../src/vba/modContentMTO.bas:4160) возвращает `dt/dd`-пары для `dl.facts`.
Новая структура — **три колонки**:

| Колонка | Элемент (dt) | Значение (dd) |
|---|---|---|
| 1 | СОБЫТИЙ (ПЛАНШЕТ, ПК) | подписанные события: `arm ∈ {ПК, ПЛАНШЕТ}`, весь снимок |
| 1 | НАРЯДОВ | без изменений — `modContentZone.OrdersCount()` |
| 2 | ОТКРЫТО ЗН > мес. | наряды без `zn_closed` и старше 30 суток от конца снимка (см. 1.3) |
| 2 | ТС по ЗН | `modContentZone.FleetCount()` — меняется только ярлык (было «Машин в парке») |
| 2 | БЕЗ ПОСТА | без изменений — `modContentZone.NoPostPct()` |
| 3 | ПОВТОРНЫЕ | возвратов по группе дефекта с начала года, окно **7 суток** (см. 1.3) |

Порядок колонок — буквально по постановке (2 + 3 + 1). Надпись **«С начала года:»** — отдельным
элементом перед `dl.facts`, живёт в шаблоне (Задача 2.4).

### 1.3 Новые счётчики в [`src/vba/modContentZone.bas`](../../src/vba/modContentZone.bas)

Публичные функции рядом с [`EventsCount()`](../../src/vba/modContentZone.bas:3619) — чтобы шапка
и слайды не разошлись:

- **`SignedEventsCount() As Double`** — число событий подписания за весь снимок:
  `arm ∈ {ПК, ПЛАНШЕТ}`. Если в снимке `mZn` поля `arm` нет — считать по снимку `tbDATA`
  через `modAggregate` с фильтром по колонке `arm` (сверить фактический список колонок).
- **`OpenOverMonth() As Double`** — наряды «открыто больше месяца»: по `mZn`,
  `CDbl(z(Z_CLOSED)) <= 0` и `SnapshotEnd() - CDbl(z(Z_DATE)) > 30`. Период — весь снимок.
- **`RetCount7() As Double`** — повторных заездов с начала года: сумма возвратов по группе
  дефекта за весь снимок с окном **7 суток** (см. Задачу 2.3).

## Задача 2. Слайд 1 — [`src/vba/modContentZone.bas`](../../src/vba/modContentZone.bas)

### 2.1 Плитки KPI — [`BuildKpiOverview()`](../../src/vba/modContentZone.bas:3380)

Целевой состав, 9 плиток, в этом порядке:

1. Нарядов открыто (не менять);
2. Закрыто нарядов (не менять);
3. Висит на конец недели (не менять);
4. **Без поста за неделю** — новая;
5. Заездов техники (не менять);
6. **ТС по ЗН** — новая: уникальных машин (`Z_VEH`), наряды которых созданы в отчётной неделе;
7. Медиана в ремзоне (не менять; подпись плитки — «Медиана в ремзоне *» или пометка `*`);
8. **Возвратов (7 дн.)** — новая: возвраты по группе дефекта, отнесённые к неделе первого
   наряда, окно **7 суток** (пометка `*`);
9. Материалы за неделю (не менять).

**Сняты из плиток:** «Висит дольше 14 суток» и «Подписей с планшета» — в постановке их нет.
Плитки убрать из вывода; вычисляющие их ряды `t14`/`tabPct` в [`Slide1Series`](../../src/vba/modContentZone.bas:3298)
можно оставить нетронутыми (снятое не удаляется).

Новые ряды в [`Slide1Series`](../../src/vba/modContentZone.bas:3298) (по неделям окна, с дельтой к ПН-1):
- `noPost` — нарядов с пустым `post`, созданных в неделю (`Z_WEEK = неделя`);
- `uniqVeh` — уникальных `Z_VEH` по нарядам недели;
- `ret7` — возвратов по неделе первого наряда (окно 7 суток).

### 2.2 Новые блоки Д1 и Д2

Новые плейсхолдеры и публичные построители (в [`FillZonePlaceholders`](../../src/vba/modContentZone.bas)):

- **`{{BLOCK_HANG_ZNTYPE}}`** ← `BuildHangByZnType()` — «Висит на конец недели ЗН по видам ремонта»:
  таблица `Вид ремонта | ЗН | %`. Определение «висит» — как `hangA` в `Slide1Series`:
  наряд без `zn_closed` (`Z_CLOSED <= 0`), созданный до конца отчётной недели
  (`Z_DATE < WeekEnd(отчётная неделя)`). Разрез — `Z_TYPE` (`zn_type`), сортировка по убыванию.
- **`{{BLOCK_HANG_STATUS}}`** ← `BuildHangByStatus()` — «Висит на конец недели по статусу»:
  та же выборка в разрезе текущего статуса `TekStatusPoDoc` (в коде — поле статуса документа
  в `mZn`; сверить индекс с фактическим набором полей снимка).

Оформление обоих — `<table>` + `div.calc-note` с описанием расчёта, классы только из словаря
контракта шаблона. Пустой результат — `.empty-note`.

### 2.3 Возвраты с окном 7 суток

Сейчас окно жёстко `RET_WINDOW = 30`. Требуется окно **7 суток** для плитки «Возвратов (7 дн.)»
и факта «ПОВТОРНЫЕ». Минимальная правка:
- в [`RetPairs()`](../../src/vba/modContentZone.bas:1722) добавить параметр окна
  `ByVal winDays As Long` (вызовы с 30 — без изменений поведения, новые вызовы — с 7);
- в [`EnsureRet()`](../../src/vba/modContentZone.bas:1780) дополнительно вычислить `mRetNumW7`
  (возвраты по группе дефекта, окно 7, счётчик по неделе первого наряда) и `mRetTot7`
  (сумма за весь снимок — для факта шапки);
- `RetCount7()` возвращает `mRetTot7`.

Ограничение «окно ещё не закрылось» (последние 7 суток снимка) для плитки за неделю не мешает:
возврат относится к неделе первого наряда, и занижение возможно только у нарядов последней
недели — указать это в `calc-note` плитки.
