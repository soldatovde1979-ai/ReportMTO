# Прогресс сборки отчёта — v1.0

**Дата:** 29.09.2026. **Основание:** владелец: «На сборку отчёта можно какой-нибудь ползунок?
… Excel всё равно висит, мне главное прогресс» [чат 29.09]. Выбран вариант А + Б.

## Что сделано (`modMain` v9.1)

- `ShowProgress(pct, stage)` — строка состояния Excel
  `Отчёт: ■■■■■□□□□□ 50 % · слайд 6 из 8: дефекты и возвраты · 42 с` и полоса на листе
  `Main` под кнопками (фигуры `PRG_TRACK`, `PRG_BAR`, `PRG_TEXT` создаются сами при первом
  запуске). После отрисовки — `DoEvents`, иначе Excel во время сборки окно не перерисовывает.
- `EndProgress(failedStage)` — успех: полоса скрывается, строка состояния сбрасывается;
  ошибка: полоса красная с названием этапа.
- Защита от повторного нажатия кнопки во время сборки (флаг `mBusy`): `DoEvents` пропускает
  клики. Флаг сбрасывается и при остановке кода кнопкой «End» в VBE (сброс проекта).
- Вне сборки отчёта (самотест, сверка плейсхолдеров) индикатор ничего не делает.

## Этапы

| % | Этап |
|---|---|
| 0–10 | подготовка, снимок `tbDATA` |
| 12–15 | запрос к ИИ; **ожидание ответа (до 60 с) — полоса стоит**: это один блокирующий вызов |
| 25–90 | слайды по одному: 1, 5, 6, 7, 8 (`FillZonePlaceholders`), 2, 3, 4 (`FillDiscPlaceholders`) |
| 94–97 | сборка HTML, сохранение |

Проценты — по порядку этапов, а не по времени: самый долгий обычно слайд 1 (первый проход
по снимку), полоса на нём задержится.

## Что проверить

Сформировать отчёт с листа `Main`: полоса появляется под кнопками, двигается по слайдам,
исчезает в конце; внизу окна — строка состояния с процентом и секундами.
