# Генератор эталона и шаблона отчёта МТО — v1.0 от 09.09.2026

Эталон `temp/MTO_макет_отчета_v4.0.html` и шаблон `temp/tmp_index_v4.0.html`
**порождаются одним кодом** и поэтому не могут разойтись по вёрстке.

## Порядок запуска

```bash
python3 compute.py      # слайды 1-4 -> metrics_a.json
python3 compute_b.py    # слайды 5-8 -> metrics_b.json
python3 render.py       # эталон: temp/MTO_макет_отчета_v4.0.html
python3 build_tpl.py    # шаблон:  temp/tmp_index_v4.0.html
python3 contract.py     # тело контракта плейсхолдеров
```

Python 3, без внешних пакетов. Источник — `data/pri.json`.
Отчётная неделя задана константой `RW` в `compute.py` и `compute_b.py`.

## Как это устроено

`render.py` оборачивает каждый кусок, который в продуктивном отчёте
генерирует VBA, в вызов `slot('ИМЯ', html)`. В эталон уходит содержимое,
в шаблон — `{{ИМЯ}}`. Проверка на роунд-трип: шаблон с подставленным
содержимым слотов совпадает с эталоном символ в символ, кроме пяти
плейсхолдеров шапки.

Правило: **менять вёрстку только здесь**, потом пересобирать оба файла.
Правка HTML руками в любом из двух файлов ломает их синхронность.
