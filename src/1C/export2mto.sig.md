# export2mto

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Серверная обработка 1С: собирает заказ-наряды за период в JSON-массив для отчёта МТО (источник данных конвейера Query-ImportJSON).

## Процедуры / Функции

### СформироватьJSONПланшетНаСервере(ДатаНачала, ДатаОкончания) : Структура
- Вход: даты начала/окончания периода (необязательные; пусто -> с 01.01 текущего года по 2050)
- Выход: Структура("Данные, Количество") — бинарный поток JSON (UTF-8, без переносов) и число записей
- Побочные эффекты: только чтение БД 1С (документы eamЗаказНаряды, регистры eamСтатусыОбъектов, уатСчетчикиТС, шхОтметкиЧекинВЗаказНарядах, справочники); записи нет
