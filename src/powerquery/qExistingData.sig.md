# qExistingData

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Отдаёт текущее содержимое листовой таблицы tbDATA (Core, generic). Вынесен отдельным запросом из-за Formula.Firewall (один запрос не может читать и файл, и книгу).

## Процедуры / Функции

### qExistingData : table
- Вход: таблица Excel tbDATA текущей книги
- Выход: её содержимое без пустых строк (отсев по пустому Key — артефакт пустой ListObject); при отсутствии таблицы — пустая таблица
- Побочные эффекты: нет побочных эффектов
