# fnDedupByKey

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Гарантия уникальности Key в newData до fnUpsert: без неё дубли одного файла прошли бы в tbDATA обеими строками.

## Процедуры / Функции

### fnDedupByKey(tbl as table) as table
- Вход: таблица с колонкой Key (и status_date для правила победителя)
- Выход: таблица без дублей Key; при совпадении остаётся запись с максимальным status_date
- Побочные эффекты: нет побочных эффектов
