# qKeepWeeks

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Читает глубину хранения tbDATA (ключ DATA/KEEP_WEEKS с листа Variable). Значение поставляется запросом, а не VBA, чтобы не плодить второй источник истины.

## Процедуры / Функции

### qKeepWeeks : number
- Вход: лист Variable, таблица tblVariable, ключ DATA/KEEP_WEEKS
- Выход: целое число недель; 0 = ретеншн выключен (ключа нет, пусто, 0 или неразборное значение)
- Побочные эффекты: нет побочных эффектов
