# fnUpsert

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Слияние новых данных с существующими по фиксированному столбцу Key (Core, generic). Новые строки замещают старые с тем же Key; невстреченные старые сохраняются.

## Процедуры / Функции

### fnUpsert(newData as table, existingData as table) as table
- Вход: две таблицы с колонкой Key; newData — свежие (типизированные) строки, existingData — текущее содержимое tbDATA
- Выход: Table.Combine({NewBuf, Cleaned}) — новые строки + старые, не имеющие Key в newData; колонки существующей таблицы выравниваются по новому набору
- Побочные эффекты: нет побочных эффектов (чистая функция; запись на лист выполняет вызывающий запрос)
