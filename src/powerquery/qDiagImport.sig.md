# qDiagImport

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Диагностический запрос выгрузки: показывает, на каком шаге падает загрузка и какие поля/значения реально приходят. В сборку и tbDATA не входит.

## Процедуры / Функции

### qDiagImport : таблица «Показатель / Значение»
- Вход: файл prmSourcePath (тот же параметр, что у Query-ImportJSON)
- Выход: таблица с показателями: число записей, поля всего / в выборке 1000 / потерянные, реальные значения ready_for и arm, неразобранные status_date, тип in_bounds, дубли Key
- Побочные эффекты: нет побочных эффектов
