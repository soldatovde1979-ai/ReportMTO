# fnComputeKey

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Power Query Custom Function (CONTENT SPEC, МТО), контракт Core §5.1. Формирует уникальный ключ `Key` строки для upsert: `number|date|ready_for|direction` с явным форматом даты и культурой (не локалезависимый).

## Процедуры / Функции

### fnComputeKey (значение функции: Compute(row as record) as text)
- Назначение: вычислить текстовый ключ строки.
- Вход: `row` — запись строки (уже типизированная); поддержка трёхаргументного `DateTime.ToText` проверяется один раз на фиктивной дате.
- Выход: текст `"number|yyyy-MM-ddTHH:mm:ss|ready_for|direction"`; null-поля дают `""`. Ключ НЕ содержит `status_date` (решение владельца процесса, v7).
- Побочные эффекты: нет.

### F(name) / D(name) (внутренние лямбды)
- Назначение: чтение поля записи с защитой от отсутствия (null → `""`); `D` форматирует дату `yyyy-MM-ddTHH:mm:ss` культурой `en-US`.
- Вход: `name` — имя поля. Выход: текст. Побочные эффекты: нет.
