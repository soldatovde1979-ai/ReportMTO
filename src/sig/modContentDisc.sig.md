# modContentDisc

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
CONTENT-слой части «Дисциплина» отчёта МТО (слайды 2–4): недельная матрица по ремзонам, площадки за отчётную неделю, таблица по сотрудникам, разбор подписей наряда, слайд 4 «не подписано». Строит HTML из снимка `tbDATA` (через `modAggregate`), примитивы разметки/графики — из `modContentZone`. Единицы счёта: матрицы/сотрудники — СОБЫТИЯ, площадки/разбор подписей — ЗАКАЗ-НАРЯДЫ. `in_bounds` не фильтруется; ФИО во внешнюю модель не уходят.

## Процедуры / Функции

### ResetDisc()
- Назначение: сброс всех агрегатов модуля (перед новым снимком).
- Вход/выход: нет. Побочные эффекты: очистка модульных переменных.

### EnsureDisc() (private)
- Назначение: один проход по снимку: события → наряды (`mOrd`) + все счётчики слайдов 2–4; вычисляет отчётную неделю.
- Вход: снимок `modAggregate` (обязателен, иначе raise). Выход: нет.
- Побочные эффекты: заполнение модульных словарей, `WriteDebug 2`.

### ZoneOf(e) / ArmField(dir, acc) / TimeField(dir, acc) (private)
- Назначение: ремзона наряда с подстановкой «(пост не указан)»; индексы полей АРМ/времени подписи по дирекции и статусу.
- Вход: массив наряда / дирекция / признак приёмки. Выход: строка/индекс. Побочные эффекты: нет.

### BuildWeeksTable(dir) : String
- Назначение: плейсхолдер `{{BLOCK_WEEKS_*}}` — матрица «% планшета» по ремзонам × 8 недель (события с известным АРМ).
- Вход: `dir` — `ДГМ`/`ДЭНТ`. Выход: HTML-фрагмент. Побочные эффекты: нет.

### BuildBlock1(sDir) : String
- Назначение: плейсхолдер `{{BLOCK_TABLE1_*}}` — Таблица 1: Всего/ПЛАНШЕТ/ПК/% планшет по неделям окна 8, ремзоны `REPORT/SLIDE_ZONES` (умолч. СТК+ПРК).
- Вход: `sDir`. Выход: HTML-фрагмент. Побочные эффекты: нет.

### PctHeat(p) : String (private)
- Назначение: цвет строки «% планшет» (0–50 % красный→жёлтый, 50–100 % жёлтый→зелёный).
- Вход: `p` — проценты. Выход: HEX-цвет. Побочные эффекты: нет.

### BuildPostsTable(dir) : String
- Назначение: плейсхолдер `{{BLOCK_POSTS_*}}` — площадки за отчётную неделю; единица — заказ-наряд; «с планшета» — все подписи дирекции за неделю с планшета.
- Вход: `dir`. Выход: HTML-фрагмент. Побочные эффекты: нет.

### BuildPeople(dir) : String
- Назначение: плейсхолдер `{{BLOCK_PEOPLE_*}}` — сотрудники: тренд % планшета за 4 недели, объём/время за отчётную неделю; порог `REPORT/MIN_RECORDS`.
- Вход: `dir`. Выход: HTML-фрагмент. Побочные эффекты: нет.

### PctArrowTd(p, hasValue, prev, hasPrev) : String (private)
- Назначение: ячейка процента со стрелкой роста/падения к предыдущей неделе.
- Вход: проценты и флаги наличия. Выход: HTML ячейки. Побочные эффекты: нет.

### AvgSpan(pk) : String (private)
- Назначение: среднее «приёмка → выбытие» в часах по нарядам, где сотрудник подписал выбытие.
- Вход: `pk` — ключ `дирекция|ФИО`. Выход: строка `ч:мм` или «—». Побочные эффекты: нет.

### BuildDepts(dir) : String
- Назначение: плейсхолдер `{{BLOCK_DEPTS_*}}` — подразделения дирекции (`emp_dep`), аналог BuildPeople.
- Вход: `dir`. Выход: HTML-фрагмент. Побочные эффекты: нет.

### AvgSpanD(dk2) : String (private)
- Назначение: среднее «приёмка → выбытие» по нарядам подразделения.
- Вход: `dk2` — ключ `дирекция|подразделение`. Выход: строка `ч:мм` или «—». Побочные эффекты: нет.

### BuildSignStat(dir) : String
- Назначение: плейсхолдер `{{BLOCK_SIGNSTAT_*}}` — разбор нарядов по подписанным статусам (оба/один/ни одного, АРМ-комбинации) + неподписанные статусы по возрасту наряда (с начала года).
- Вход: `dir`. Выход: HTML-фрагмент. Побочные эффекты: нет.

### SsRow(lab, v, den, indent) : String (private)
- Назначение: строка таблицы разбора подписей.
- Вход: подпись, значение, знаменатель, отступ. Выход: HTML-строка. Побочные эффекты: нет.

### AgeBucket4(dser) : Long (private)
- Назначение: возраст наряда, 4 корзины (сутки/неделя/месяц/больше).
- Вход: серийная дата создания. Выход: индекс 0–3 или −1. Побочные эффекты: нет.

### BuildNoSignSplit(sDir, fld, emptyLab, colLab) : String
- Назначение: плейсхолдеры `{{BLOCK_NOSIGN_STATUS_*}}`/`{{BLOCK_NOSIGN_TYPE_*}}` — наряды без единой подписи в разрезе поля (статус документа/вид ремонта), таблица + график.
- Вход: дирекция (не влияет на отбор), индекс поля, подпись пустого, заголовок разреза. Выход: HTML-фрагмент. Побочные эффекты: нет.

### SignedCount(e) : Long (private)
- Назначение: число подписей с АРМ ПК/ПЛАНШЕТ среди 4 строк наряда.
- Вход: массив наряда. Выход: 0–4. Побочные эффекты: нет.

### BuildKpiUnsigned() : String
- Назначение: плейсхолдер `{{KPI_UNSIGNED}}` — плитки слайда 4: нарядов без подписей, событий «НЕ ПОДПИСАНО», частично подписанных, самый старый.
- Вход: нет. Выход: HTML-фрагмент. Побочные эффекты: нет.

### UnsignedBy(fld, emptyLab) : Object (private)
- Назначение: счётчик нарядов без единой подписи по значению поля.
- Вход: индекс поля, подпись пустого. Выход: Dictionary. Побочные эффекты: нет.

### BuildUnsignedAge() : String
- Назначение: плейсхолдер `{{BLOCK_UNSIGNED_AGE}}` — возраст неподписанных нарядов (5 корзин).
- Вход: нет. Выход: HTML-фрагмент. Побочные эффекты: нет.

### BuildUnsignedPost() : String
- Назначение: плейсхолдер `{{BLOCK_UNSIGNED_POST}}` — неподписанные наряды по `postN`.
- Вход: нет. Выход: HTML-фрагмент. Побочные эффекты: нет.

### BuildUnsignedOwner() : String
- Назначение: плейсхолдер `{{BLOCK_UNSIGNED_OWNER}}` — неподписанные наряды по `owner_dep`.
- Вход: нет. Выход: HTML-фрагмент. Побочные эффекты: нет.

### BuildUnsignedZnType() : String
- Назначение: плейсхолдер `{{BLOCK_UNSIGNED_ZNTYPE}}` — неподписанные наряды по `zn_type`.
- Вход: нет. Выход: HTML-фрагмент. Побочные эффекты: нет.

### FillDiscPlaceholders(d) 
- Назначение: точка входа — заполнение словаря плейсхолдеров слайдов 2–4 для обеих дирекций.
- Вход: `d` — словарь `{{ИМЯ}} → значение`. Выход: нет (мутация словаря).
- Побочные эффекты: заполняет 23 ключа (`BLOCK_WEEKS/TABLE1/POSTS/PEOPLE/DEPTS/SIGNSTAT/NOSIGN_STATUS/NOSIGN_TYPE_{DENT,DGM}`, `KPI_UNSIGNED`, `BLOCK_UNSIGNED_AGE/POST/OWNER/ZNTYPE`); `WriteDebug 1`.
