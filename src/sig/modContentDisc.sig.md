# modContentDisc

Статус: CLEAN
Обновлено: 17.09.2026

## Назначение
CONTENT-слой части «Дисциплина» отчёта МТО (слайды 2–4): недельная матрица по ремзонам, приёмка против выдачи, площадки за отчётную неделю, таблицы по сотрудникам и подразделениям, разбор подписей наряда, слайд 4 «не подписано». Строит HTML из снимка `tbDATA` (через `modAggregate`), примитивы разметки/графики — из `modContentZone`. Единицы счёта: матрицы/люди/подразделения/приёмка-выдача — СОБЫТИЯ подписания; площадки/разбор подписей — ЗАКАЗ-НАРЯДЫ. `in_bounds` не фильтруется; ФИО во внешнюю модель не уходят. Версия кода 1.3 (17.09.2026).

## Процедуры / Функции

### ResetDisc()
- Назначение: сброс всех агрегатов модуля перед новым снимком.
- Вход: нет. Выход: нет.
- Побочные эффекты: очистка модульных переменных (словари и счётчики).

### EnsureDisc() (private)
- Назначение: один проход по снимку: события → наряды `mOrd` (14 полей: даты, АРМ и время подписей по дирекциям/статусам, TekStatusPoDoc) + все счётчики слайдов 2–4, включая новые `mALTot`/`mALTab` (разрез A=«Готов к приемке» / L=«Готов к выбытию»); вычисляет отчётную неделю.
- Вход: снимок `modAggregate` (обязателен, иначе raise `vbObjectError+42`).
- Выход: нет.
- Побочные эффекты: заполнение модульных словарей, `WriteDebug 2`.

### ZoneOf(e) / ArmField(dir, acc) / TimeField(dir, acc) (private)
- Назначение: ZoneOf — нормализованная ремзона наряда («(пост не указан)» при пустоте); ArmField/TimeField — индекс поля АРМ/времени подписи по дирекции и статусу (приёмка/выбытие).
- Вход: запись наряда `mOrd`, дирекция «ДГМ»/«ДЭНТ», флаг приёмки.
- Выход: String / Long-индекс поля.
- Побочные эффекты: нет.

### BuildWeeksTable(dir)
- Назначение: `{{BLOCK_WEEKS_*}}` — матрица «% планшета» по ремзонам и неделям окна 8 недель, строки «Все ремзоны» и «Событий всего».
- Вход: дирекция (String). Выход: HTML-строка (пусто — EmptyNote).
- Побочные эффекты: EnsureDisc; чтение переменной `REPORT/...` не делает.

### BuildBlock1(sDir)
- Назначение: «Таблица 1» (Б5) — события подписания по неделям в разрезе ПК/ПЛАНШЕТ для набора ремзон `REPORT/SLIDE_ZONES`. ОСТАВЛЕНА НЕВЫЗЫВАЕМОЙ (дублировала BLOCK_WEEKS_*).
- Вход: дирекция. Выход: HTML-строка.
- Побочные эффекты: EnsureDisc; чтение `modMain.GetVariableDef("REPORT/SLIDE_ZONES")`.

### PctHeat(p) (private)
- Назначение: цвет строки «% планшет» шкалой modColor.PercentToColor.
- Вход: процент 0–100. Выход: CSS-цвет.
- Побочные эффекты: нет.

### BuildAccLev(dir)
- Назначение: НОВОЕ v1.3 — `{{BLOCK_ACCLEV_*}}` «приёмка против выдачи»: % планшета раздельно по статусам «Готов к приемке» (A) и «Готов к выбытию» (L), по неделям окна 8 + вывод о разрыве (гипотеза: выдача подписывается за ПК).
- Вход: дирекция. Выход: HTML-строка (таблица 2×3 строк на статус + вывод).
- Побочные эффекты: EnsureDisc; только чтение mALTot/mALTab.

### BuildPostsTable(dir)
- Назначение: `{{BLOCK_POSTS_*}}` — площадки за отчётную неделю; единица счёта ЗАКАЗ-НАРЯД («с планшета» = все подписи дирекции за неделю с планшета); набор строк `REPORT/ZONES_ALL` (по умолчанию SLIDE_ZONES + все postN), ремзоны без нарядов — нулями.
- Вход: дирекция. Выход: HTML-строка.
- Побочные эффекты: EnsureDisc; чтение `REPORT/ZONES_ALL`, `REPORT/SLIDE_ZONES`.

### BuildPeople(dir)
- Назначение: `{{BLOCK_PEOPLE_*}}` — сотрудники дирекции: тренд % планшета за 4 недели (стрелки к предыдущей), справа объём/планшет/приёмка/выбытие/среднее время за отчётную неделю; порог включения `REPORT/MIN_RECORDS`.
- Вход: дирекция. Выход: HTML-строка.
- Побочные эффекты: EnsureDisc; чтение `REPORT/MIN_RECORDS`.

### PctArrowTd(p, hasValue, prev, hasPrev) (private)
- Назначение: ячейка процента со стрелкой ↑/↓ к предыдущей неделе.
- Вход: проценты текущей и предыдущей недель с флагами наличия. Выход: HTML-ячейка.
- Побочные эффекты: нет.

### AvgSpan(pk) (private)
- Назначение: среднее «приёмка → выбытие» в часах по нарядам, где сотрудник подписал выбытие.
- Вход: ключ «дирекция|ФИО». Выход: строка времени (Hh) или «—».
- Побочные эффекты: чтение mPPairs/mOrd.

### BuildDepts(dir)
- Назначение: `{{BLOCK_DEPTS_*}}` — подразделения дирекции (аналог BuildPeople без ФИО); ключи агрегатов содержат дирекцию (R9).
- Вход: дирекция. Выход: HTML-строка.
- Побочные эффекты: EnsureDisc.

### AvgSpanD(dk2) (private)
- Назначение: среднее «приёмка → выбытие» по нарядам подразделения (аналог AvgSpan на mDPairs).
- Вход: ключ «дирекция|подразделение». Выход: строка времени или «—».
- Побочные эффекты: чтение mDPairs/mOrd.

### BuildSignStat(dir)
- Назначение: `{{BLOCK_SIGNSTAT_*}}` — разбор нарядов дирекции по подписанным статусам (оба/один/ни одного, сочетания АРМ) + график неподписанных статусов по возрасту наряда.
- Вход: дирекция. Выход: HTML-строка.
- Побочные эффекты: EnsureDisc; InYtdOrd.

### SsRow(lab, v, den, indent) (private)
- Назначение: строка таблицы разбора подписей.
- Вход: подпись, значение, знаменатель, флаг отступа. Выход: HTML-строка.
- Побочные эффекты: нет.

### AgeBucket4(dser) (private)
- Назначение: возраст наряда — корзина (до суток / неделя / месяц / больше; -1 нет даты).
- Вход: серийная дата создания. Выход: индекс 0–3 или -1.
- Побочные эффекты: нет.

### BuildNoSignSplit(fld, emptyLab, colLab)
- Назначение: `{{BLOCK_NOSIGN_*}}` — наряды без единой подписи (SignedCount=0) в разрезе поля (E_TYPE или E_TEK) с процентами; v1.2: параметр дирекции убран, блок на слайде 4.
- Вход: индекс поля записи наряда, подпись пустого значения, заголовок колонки.
- Выход: HTML-строка.
- Побочные эффекты: EnsureDisc.

### SignedCount(e) (private)
- Назначение: сколько из 4 подписей наряда (ПК/ПЛАНШЕТ).
- Вход: запись наряда mOrd. Выход: 0–4.
- Побочные эффекты: нет.

### BuildKpiUnsigned()
- Назначение: `{{KPI_UNSIGNED}}` — плитки слайда 4: нарядов без подписей, событий «НЕ ПОДПИСАНО», подписан частично, самый старый.
- Вход: нет. Выход: HTML-строка.
- Побочные эффекты: EnsureDisc.

### UnsignedBy(fld, emptyLab) (private)
- Назначение: счётчик нарядов без подписей по значению поля.
- Вход: индекс поля, подпись пустого. Выход: Dictionary.
- Побочные эффекты: EnsureDisc.

### BuildUnsignedAge()
- Назначение: `{{BLOCK_UNSIGNED_AGE}}` — возраст нарядов без подписей (5 корзин) с подписью даты обреза снимка.
- Вход: нет. Выход: HTML-строка.
- Побочные эффекты: EnsureDisc.

### BuildUnsignedPost()
- Назначение: `{{BLOCK_UNSIGNED_POST}}` — наряды без подписей в разрезе postN (топ-6).
- Вход: нет. Выход: HTML-строка.
- Побочные эффекты: UnsignedBy.

### BuildUnsignedOwner()
- Назначение: `{{BLOCK_UNSIGNED_OWNER}}` — наряды без подписей в разрезе owner_dep (топ-6).
- Вход: нет. Выход: HTML-строка.
- Побочные эффекты: UnsignedBy.

### BuildUnsignedZnType()
- Назначение: наряды без подписей в разрезе zn_type. ОСТАВЛЕНА НЕВЫЗЫВАЕМОЙ (заменена BLOCK_NOSIGN_TYPE).
- Вход: нет. Выход: HTML-строка.
- Побочные эффекты: UnsignedBy.

### FillDiscPlaceholders(d)
- Назначение: точка входа слайдов 2–4: заполняет плейсхолдеры BLOCK_WEEKS_*/BLOCK_ACCLEV_*/BLOCK_POSTS_*/BLOCK_PEOPLE_*/BLOCK_DEPTS_*/BLOCK_SIGNSTAT_* для ДЭНТ и ДГМ + слайд 4 (KPI_UNSIGNED, BLOCK_UNSIGNED_*, BLOCK_NOSIGN_TYPE/STATUS); подпись периода PeriodCap централизованно.
- Вход: словарь плейсхолдеров d. Выход: нет.
- Побочные эффекты: EnsureDisc; запись в d; WriteDebug 1 по слайдам.
