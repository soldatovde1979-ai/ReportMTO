# qProf5_Dedup

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Диагностический профиль конвейера `Query-ImportJSON` (шаг `Deduped`): число строк после `fnDedupByKey` (дедупликация по `Key`, выживает максимальный `status_date`). В сборку не входит, в `tbDATA` не грузится.

## Процедуры / Функции

### qProf5_Dedup (запрос)
- Назначение: профилирование шага дедупликации.
- Вход: `prmSourcePath` — файл или папка.
- Выход: таблица `#table({"Rows"}, ...)` с числом строк `Deduped`.
- Побочные эффекты: чтение JSON-файлов; записей нет.
