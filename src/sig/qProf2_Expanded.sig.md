# qProf2_Expanded

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Диагностический профиль конвейера `Query-ImportJSON` (шаг `Expanded`): число строк таблицы после `Table.FromRecords` по объединению полей выборки первых 1000 записей. В сборку не входит, в `tbDATA` не грузится.

## Процедуры / Функции

### qProf2_Expanded (запрос)
- Назначение: профилирование шага `Expanded` (полнота набора колонок).
- Вход: `prmSourcePath` — файл или папка.
- Выход: таблица `#table({"Rows"}, ...)` с числом строк `Expanded`.
- Побочные эффекты: чтение JSON-файлов; записей нет.
