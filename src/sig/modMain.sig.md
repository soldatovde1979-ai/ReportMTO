# modMain

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
CORE-модуль, оркестрация (Architecture Core §11). Обработчики кнопок «Загрузить»/«Сформировать отчёт» листа Main, работа с листом `Variable`, резолвер ключа ИИ, управление PQ-параметром `prmSourcePath`. Реализация блоков вызывается по фиксированным именам из `modContentMTO`.

## Процедуры / Функции

### LoadSourceFile()
- Назначение: обработчик «Загрузить»: выбор JSON-файла, запись в `prmSourcePath`, синхронный Refresh PQ, пересчёт блоков.
- Вход: нет (файл — через диалог `GetOpenFilename`).
- Выход: нет.
- Побочные эффекты: обновление параметра PQ, обновление импорта (данные `tbDATA` меняются), вехи/тайминги в журнал, пересчёт сводок `modContentMTO.BuildPivots`.

### LoadPackage()
- Назначение: обработчик «Загрузить пакет»: полная пересборка `tbDATA` из всех `*.json` папки `DATA/SOURCE_FOLDER` одним проходом PQ.
- Вход: ключи листа `Variable`: `DATA/SOURCE_FOLDER`, `DATA/LAST_LOAD_SECONDS`, `DATA/LAST_LOAD_ROWS`.
- Выход: нет.
- Побочные эффекты: очистка логов и `tbDATA`, манифест очереди файлов (веха), прогноз ожидания в `StatusBar`, Refresh PQ, запись `DATA/LAST_LOAD_*`, веха «Записано N из M», `BuildPivots`.

### ListJsonFiles(folder) : Variant (private)
- Назначение: список `*.json` верхнего уровня папки, отсортированный по штампу из имени.
- Вход: `folder` — путь. Выход: 0-based массив путей или `Empty`. Побочные эффекты: нет.

### StampFromName(fileName) : String (private)
- Назначение: извлечь `YYYYMMDD_HHMMSS` из имени файла; `""`, если шаблон не найден.
- Вход: `fileName`. Выход: штамп 15 символов. Побочные эффекты: нет.

### IsDigits(s) : Boolean (private)
- Назначение: строка непустая и состоит только из цифр.
- Вход: `s`. Выход: True/False. Побочные эффекты: нет.

### RecFromName(fileName) : Long (private)
- Назначение: число записей из `_NNNNNrec.json`; 0 при нераспознанном имени.
- Вход: `fileName`. Выход: число. Побочные эффекты: нет.

### SumRecsFromNames(files) : Long (private)
- Назначение: сумма счётчиков `rec` из имён файлов (нераспознанные дают 0).
- Вход: массив путей. Выход: сумма. Побочные эффекты: нет.

### ClearTbData() (private)
- Назначение: подготовка `tbDATA` к полной пересборке (удаление строк не выполняется — таблицу затирает сам Power Query; раньше удаление зависало на 255k строках).
- Вход/выход: нет. Побочные эффекты: нет (по текущей реализации).

### ClearLogs() (private)
- Назначение: очистить `tbLogs` (после загрузки пакета остаётся только итог).
- Вход/выход: нет. Побочные эффекты: удаление строк данных `tbLogs`.

### BackupWorkbook() (private)
- Назначение: копия книги в `bak\ReportMTO.xlsm.bak_YYYYMMDD_HHMMSS`.
- Вход/выход: нет. Побочные эффекты: создание папки `bak` и файла копии (SaveCopyAs), запись в журнал.

### SetSourcePathParameter(filePath) (private)
- Назначение: записать путь в PQ-параметр `prmSourcePath` ВМЕСТЕ с meta-записью (иначе параметр «разжалуется» в обычный запрос и Formula Firewall отклоняет обновление).
- Вход: `filePath` — файл или папка. Выход: нет. Побочные эффекты: изменение `ThisWorkbook.Queries("prmSourcePath").Formula`; при отсутствии query — raise с пояснением.

### GenerateReport()
- Назначение: обработчик «Сформировать отчёт»: проверки, пересчёт блоков, вызов ИИ (не блокирует отчёт), сборка плейсхолдеров, рендер и сохранение HTML.
- Вход: ключи `AI/ENDPOINT`, `OUTPUT/RESULT_FOLDER`; ключ ИИ через `ResolveAiApiKey`; выводы ИИ через `ParseAIResponse`.
- Выход: нет.
- Побочные эффекты: чтение листа `Variable`, HTTP-вызов внешнего ИИ (деградирует до заглушек), запись HTML-файла отчёта, журнал вех/ошибок, `StatusBar`.

### DebugGenerateOffline()
- Назначение: отладочный прогон без вызова ИИ: отчёт с гарантированными заглушками выводов.
- Вход: нет. Выход: нет. Побочные эффекты: `BuildPivots`, рендер и запись `debug_yyyymmdd_hhnnss.html` в папку результата.

### SafeRowCount() : Long (private)
- Назначение: число строк `tbDATA` без падения при её отсутствии.
- Вход: нет. Выход: число строк (0 при ошибке). Побочные эффекты: нет.

### ResolveAiApiKey() : String
- Назначение: резолвер ключа ИИ: `AI_API_KEY` (env) → `%APPDATA%\ReportMTO\deepseek.key` → лист `Variable` (legacy, с предупреждением). Ключ не пишется в лог/HTML.
- Вход: нет. Выход: ключ (возможно `""`). Побочные эффекты: чтение env/файла/листа; диагностика источника и длины ключа в журнал (без секрета).

### CleanApiKey(raw) : String (private)
- Назначение: очистить ключ от BOM/управляющих символов/пробелов/кавычек перед заголовком Authorization.
- Вход: `raw`. Выход: чистый ключ. Побочные эффекты: нет.

### ReadKeyFile(path) : String (private)
- Назначение: чтение файла ключа UTF-8; отсутствие/ошибка — `""`.
- Вход: `path`. Выход: содержимое. Побочные эффекты: чтение файла.

### GetVariable(key) : String
- Назначение: значение из листа `Variable` (таблица Key/Value); отсутствие ключа — raise `vbObjectError+1`.
- Вход: `key`. Выход: значение строкой. Побочные эффекты: чтение листа.

### GetVariableDef(key, defaultValue) : String
- Назначение: значение необязательного ключа; отсутствие/пусто — `defaultValue`.
- Вход: `key`, `defaultValue`. Выход: значение. Побочные эффекты: чтение листа.

### SetVariable(key, value)
- Назначение: записать значение ключа на листе `Variable`; при отсутствии ключа — добавить строку в конец таблицы.
- Вход: `key`, `value`. Выход: нет. Побочные эффекты: запись в таблицу `Variable`.
