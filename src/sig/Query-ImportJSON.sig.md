# Query-ImportJSON

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Power Query запрос (CORE, generic ETL-пайплайн, Architecture Core §5/§5.1). Основной импортный запрос: читает выгрузку 1С (файл или папку), нормализует, считает ключи и дельты, сливает с существующей `tbDATA` (upsert), применяет ретеншн и возвращает итоговую таблицу на лист `tbDATA`. Вызывает по фиксированным именам контракта: `fnNormalizeFields`, `fnComputeKey`, `fnDedupByKey`, `fnComputeGroupMetrics`, `fnUpsert`, `qExistingData`, `qKeepWeeks`.

## Процедуры / Функции

### Query-ImportJSON (запрос)
- Назначение: ETL-конвейер выгрузки.
- Вход: `prmSourcePath` — именованный параметр (путь к файлу `.json` ИЛИ папке с `*.json`; задаётся из VBA перед Refresh); `qExistingData` — текущее содержимое `tbDATA`; `qKeepWeeks` — глубина ретеншна с листа `Variable`.
- Выход: `Retained` — таблица для загрузки в `tbDATA`: в режиме папки — все файлы одним проходом (полная пересборка, без upsert); в режиме файла — `fnUpsert(NewData, ExistingData)`; финальный шаг удаляет строки старше `DATA/KEEP_WEEKS` недель (отсечка — понедельник недели от максимальной даты `status_date`/`date`; строки без распознанной опорной даты сохраняются).
- Побочные эффекты: чтение JSON-файлов (кодовая страница 65001), чтение книги (`qExistingData`, `qKeepWeeks`); при загрузке в Excel — замена содержимого `tbDATA`.

### ExtractStamp(name) / SortKey(name) / IsFolder (внутренние лямбды/шаги)
- Назначение: извлечь дату/время `\d{8}_\d{6}` из имени файла; ключ сортировки очереди файлов; признак «папка или файл».
- Вход: имя файла / значение `prmSourcePath`.
- Выход: штамп/ключ/логическое.
- Побочные эффекты: нет.

### ToDT(v) / RowAnchor(r) / ColDates(t, col) (внутренние лямбды)
- Назначение: терпимое приведение значения к datetime; опорная дата строки (`status_date`, иначе `date`); даты столбца без null.
- Вход: значения/запись/таблица.
- Выход: nullable datetime / список дат.
- Побочные эффекты: нет.
