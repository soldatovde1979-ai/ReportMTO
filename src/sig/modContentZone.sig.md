# modContentZone

Статус: CLEAN
Обновлено: 17.09.2026

## Назначение
CONTENT-слой части «Техника» отчёта МТО (слайды 1 и 5–8) + общие примитивы для `modContentDisc`. За один проход по снимку `tbDATA` строит уровни: события → заказы-наряды (`mZn`, 24 поля) → машины и заезды (`mVeh`). Считает парк, заезды, возвраты (три уровня строгости, окна 7/30 суток), фазы наряда, хвост незакрытого, износ по счётчику, план/факт трудозатрат, материалы (ABC), качество учёта, заявку в 1С. Версия кода 2.12 (17.09.2026): знак % во всех процентах, конкретные даты в подписях периода.

- Выход: нет.
