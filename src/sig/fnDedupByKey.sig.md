# fnDedupByKey

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Power Query Custom Function (CONTENT SPEC, МТО), введена v7. Обеспечивает уникальность `Key` ВНУТРИ одного файла перед передачей в `fnUpsert` (fnUpsert дедуплицирует только между загрузками). Правило победителя: при совпадении `Key` остаётся запись с максимальным `status_date`.

## Процедуры / Функции

### fnDedupByKey(tbl as table) as table
- Назначение: дедупликация строк по `Key` (выживает самая поздняя по `status_date`).
- Вход: `tbl` — таблица с `Key` и `status_date` (или без них — тогда вернётся как есть).
- Выход: таблица с уникальными `Key`; при отсутствии столбца `Key` — входная таблица без изменений.
- Побочные эффекты: нет; `Table.Buffer` перед `Table.Distinct` для детерминированности порядка.
