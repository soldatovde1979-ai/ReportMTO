# fnUpsert

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Power Query Custom Function (CORE, generic). Полная замена строк по ключу: строки `newData` ЗАМЕЩАЮТ строки `existingData` с тем же `Key`; строки existingData, которых нет в newData, сохраняются. Накопительная семантика: загрузка нескольких файлов копит данные (порядок загрузки решает победителя).

## Процедуры / Функции

### fnUpsert(newData as table, existingData as table) as table
- Назначение: слить новую таблицу с существующей по `Key` (LeftAnti-join на хэш-соединении движка).
- Вход: `newData` — новая таблица (столбец `Key` обязателен); `existingData` — текущая (`Key` обязателен).
- Выход: объединённая таблица: набор и порядок колонок — от `newData`; unmatched-старые строки с `MissingField.UseNull`.
- Побочные эффекты: нет (функция); в контексте запроса читает и пишет `tbDATA` (самоссылающийся запрос).
