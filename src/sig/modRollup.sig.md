# modRollup

Статус: CLEAN
Обновлено: 29.09.2026

## Назначение
CORE-модуль, v1.0. Понедельная свёртка истории `tbDATA` в таблицу `tbARCHIVE` перед загрузкой данных: события старше окна хранения не удаляются молча, а сворачиваются в строки «ISO-неделя × аналитики» со счётчиками. Водяной знак `DATA/ROLLUP_UNTIL` (лист `Variable`) — до этой даты история свёрнута; ретеншн Power Query (`qRollupUntil`) удаляет только строки старше знака. Постановка — `docs/plans/tz_svertka_istorii_v1.0.md`.

## Процедуры / Функции

### RollupBeforeLoad() : Long
- Назначение: свернуть события с опорной датой (max `status_date`, `date`) в [водяной знак; отсечка) в `tbARCHIVE` и сдвинуть знак на отсечку. Отсечка — правилом R-1 `Query-ImportJSON` (понедельник недели последней даты минус `KEEP_WEEKS`−1 недель).
- Вход: лист `Variable` (`DATA/ROLLUP`, `DATA/KEEP_WEEKS`, `DATA/ROLLUP_UNTIL`), таблица `tbDATA`.
- Выход: число свёрнутых событий; `0` — нечего сворачивать или выключено; `-1` — ошибка (наружу не бросается).
- Побочные эффекты: строки в `tbARCHIVE` (создаёт лист/таблицу при первом запуске); `SetVariable DATA/ROLLUP_UNTIL` — ТОЛЬКО после успешной записи архива; веха в журнал.

### RollupNow()
- Назначение: ручной запуск свёртки (Alt+F8). Свёрнутые строки удалит следующая загрузка.
- Вход: нет. Выход: нет. Побочные эффекты: как `RollupBeforeLoad`, веха в журнал.

### Watermark() : Double
- Назначение: водяной знак свёртки (серийная дата без времени).
- Вход: ключ `DATA/ROLLUP_UNTIL`. Выход: дата; `0` — свёртки не было. Побочные эффекты: нет.

### LastRolled() : Long
- Назначение: число событий, свёрнутых последним запуском. Побочные эффекты: нет.

### ArchiveTabletByMonth(dirName As String, tot As Object, tab1 As Object) : Long
- Назначение: добавить в словари подписанные события архива по месяцам дирекции (`tot` — с известным АРМ, `tab1` — с планшета; ключ — год×100+месяц текстом).
- Вход: дирекция, два `Scripting.Dictionary`.
- Выход: число прочитанных строк архива (`0` — архива нет).
- Побочные эффекты: изменяет переданные словари; при ошибке чтения — предупреждение в журнал.

### WriteArchive(grp As Object, ords As Object) (private)
- Назначение: дописать сгруппированные счётчики в `tbARCHIVE` одним блоком и расширить таблицу.
- Побочные эффекты: запись на лист `tbARCHIVE`.

### EnsureArchiveTable() : ListObject (private)
- Назначение: найти или создать лист и таблицу `tbARCHIVE` с 16 колонками.
- Побочные эффекты: может добавить лист в книгу; веха в журнал.

### FindTable, ColOf, Anchor, Txt, SafeLong (private)
- Назначение: поиск ListObject по имени, индекс колонки по заголовку, опорная дата строки (max `status_date`, `date`), текст ячейки без `|`, безопасное целое из текста.
- Побочные эффекты: нет.
