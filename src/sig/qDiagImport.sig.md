# qDiagImport

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Power Query ДИАГНОСТИЧЕСКИЙ запрос (v5). В сборку не входит, в `tbDATA` не грузится, ничего не меняет. Показывает, на каком шаге падает загрузка: сводка по числу записей, полному составу полей, потерянным полям выборки 1000, реальным написаниям `ready_for`/`arm`, неразобранным `status_date`, типу `in_bounds`, числу дублей `Key` внутри файла.

## Процедуры / Функции

### qDiagImport (запрос)
- Назначение: диагностическая сводка выгрузки (одна таблица «Показатель | Значение»).
- Вход: файл из параметра `prmSourcePath` (`Json.Document(File.Contents(...), 65001)`).
- Выход: таблица `Summary` из пар «Показатель»/«Значение»: записей в JSON, полей всего, полей в выборке 1000, потерянных полей, неразобранных `status_date`, типа `in_bounds`, дублей `Key`; промежуточные шаги (`Source`, `RecordCount`, `FieldsAll`, `FieldsSample`, `FieldsMissed`, `StatusValues`, `ArmValues`, `BadDates`, `InBoundsType`, `DupKeys`) смотрятся пошагово в редакторе.
- Побочные эффекты: чтение JSON-файла; записей нет.
