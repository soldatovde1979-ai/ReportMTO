# qExistingData

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Power Query запрос (CORE, generic), v5. Отдаёт текущее содержимое листовой таблицы `tbDATA` для слияния в `fnUpsert`. Выделен отдельным запросом, потому что Power Query не позволяет одному запросу читать и файл-источник, и книгу (изоляция партиций). Загружается ТОЛЬКО как подключение, не на лист.

## Процедуры / Функции

### qExistingData (запрос)
- Назначение: вернуть содержимое `tbDATA` без лишних пустых строк.
- Вход: таблица Excel `tbDATA` (`Excel.CurrentWorkbook`); при её отсутствии — пустая таблица.
- Выход: буферизованная таблица; при наличии столбца `Key` отсеиваются строки с пустым `Key` (пустая строка, которую Excel оставляет в пустом ListObject).
- Побочные эффекты: чтение книги; записей нет.
