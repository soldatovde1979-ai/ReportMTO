# qProf7_Retention

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Диагностический профиль конвейера `Query-ImportJSON` (шаг `Retained`): число строк после применения ретеншна (`DATA/KEEP_WEEKS`). В сборку не входит, в `tbDATA` не грузится.

## Процедуры / Функции

### qProf7_Retention (запрос)
- Назначение: профилирование финального шага ретеншна.
- Вход: `prmSourcePath` — файл или папка; глубина ретеншна из `qKeepWeeks` (в профиле зафиксирована `KeepWeeks = 0` — шаг не выполняется).
- Выход: таблица `#table({"Rows"}, ...)` с числом строк `Retained`.
- Побочные эффекты: чтение JSON-файлов; записей нет.
