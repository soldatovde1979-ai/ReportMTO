# qRollupUntil

Статус: CLEAN
Обновлено: 29.09.2026

## Назначение
Power Query запрос (CORE, generic), v9.0. Водяной знак свёртки истории: дата, до которой (не включая) события `tbDATA` уже свёрнуты в `tbARCHIVE` модулем `modRollup`. Источник — лист `Variable`, таблица `tblVariable`, ключ `DATA/ROLLUP_UNTIL`. Загружается ТОЛЬКО как подключение.

## Процедуры / Функции

### qRollupUntil (запрос)
- Назначение: вернуть водяной знак для шага ретеншна `Query-ImportJSON` (R-1, `EffCutoff`).
- Вход: `tblVariable` (столбцы `Key`, `Value`).
- Выход: `null` — ключа нет (прежний ретеншн); `#date(1900,1,1)` — ключ есть, но пуст или не разбирается (удалять нельзя ничего); иначе дата из ячейки (дата, серийное число или текст `ГГГГ-ММ-ДД`).
- Побочные эффекты: чтение книги; записей нет.
