# modHTMLEngine

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
CORE-модуль, generic движок шаблона: читает HTML-шаблон (`tmp_index.html`) в UTF-8, подставляет значения плейсхолдеров из словаря `{{ИМЯ}} → значение`, экранирует HTML, сохраняет готовый отчёт в UTF-8 без BOM в папку результата. Не знает конкретных имён плейсхолдеров — их список строит Content Spec (`modContentMTO.BuildPlaceholders`).

## Процедуры / Функции

### RenderTemplate(templatePath As String, placeholders As Object) : String
- Назначение: читает файл шаблона и заменяет в тексте все токены `{{ключ}}` значениями из переданного словаря.
- Вход: `templatePath` — полный путь к HTML-шаблону; `placeholders` — `Scripting.Dictionary`, ключи без скобок (`"BLOCK_1"` → заменяется `{{BLOCK_1}}`).
- Выход: готовый HTML-текст отчёта.
- Побочные эффекты: чтение файла с диска; записей не делает.

### SaveHTMLFile(html As String, resultFolder As String) : String
- Назначение: сохраняет готовый отчёт в папку результата с именем `Report_yyyymmdd_hhnnss.html`.
- Вход: `html` — текст отчёта; `resultFolder` — путь из ключа `OUTPUT/RESULT_FOLDER` (может быть пустым/недоступным).
- Выход: полный путь сохранённого файла; `""` при ошибке (файл не записан).
- Побочные эффекты: создаёт папку результата при необходимости (один уровень); при недоступности — резервная папка `result` рядом с книгой; пишет запись в журнал `modLog.WriteLogEntry` (Ошибка/Предупреждение).

### EnsureFolder(path As String) : String (private)
- Назначение: вернуть путь, если папка существует или её удалось создать.
- Вход: `path` — проверяемый/создаваемый путь.
- Выход: путь или `""`, если папки нет и создать не удалось.
- Побочные эффекты: создание папки; ошибки создания гасятся (недоступный путь — штатная ситуация).

### ReadUtf8(path As String) : String
- Назначение: прочитать текстовый файл как UTF-8 через ADODB.Stream.
- Вход: `path` — путь к файлу.
- Выход: содержимое файла строкой.
- Побочные эффекты: снимает BOM (U+FEFF) в начале строки; чтение с диска.

### WriteUtf8(path As String, content As String)
- Назначение: записать текст в файл в UTF-8 БЕЗ BOM.
- Вход: `path` — путь записи; `content` — текст.
- Выход: нет.
- Побочные эффекты: перезапись файла на диске (через ADODB.Stream, бинарный перенос после отсечения BOM).

### HtmlEscape(s As String) : String
- Назначение: экранировать HTML-спецсимволы для безопасной вставки значений в разметку.
- Вход: `s` — произвольная строка (поля 1С, текст внешнего ИИ).
- Выход: экранированная строка (`& < > " '`).
- Побочные эффекты: нет.

### ResolveOutputFolder(raw As String) : String
- Назначение: развернуть путь из листа `Variable` в реальный путь папки выдачи: токены `%проект%`/`%project%` (папка книги), переменные окружения `%VAR%`, относительные `.\` и `..\`, нормализация через FSO.
- Вход: `raw` — сырое значение ключа; пустое → `.\result`.
- Выход: нормализованный абсолютный путь без хвостового слэша.
- Побочные эффекты: нет (только разбор строки); неизвестный `%токен%` остаётся как есть.
