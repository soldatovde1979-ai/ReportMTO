# fnComputeGroupMetrics

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Power Query Custom Function (CONTENT SPEC, МТО), контракт Core §5.1. Вычисляет «дельту статусов»: часы между приёмкой и выбытием по паре (наряд, дирекция) — Отчёт №1.

## Процедуры / Функции

### fnComputeGroupMetrics(tbl as table) as table
- Назначение: добавить в таблицу столбец `deltaHours` = часы между минимальной `status_date` «Готов к приемке» и максимальной `status_date` «Готов к выбытию» в группе (`number`, `direction`); значение присваивается только строкам «Готов к выбытию».
- Вход: `tbl` — вся таблица после добавления `Key`, с типизированными `ready_for`/`status_date`.
- Выход: таблица с дополнительным столбцом `deltaHours` (nullable number).
- Побочные эффекты: нет (чистая функция); чтение/запись внешних источников отсутствуют.

### Norm(v) (внутренняя лямбда)
- Назначение: нормализация `ready_for`: null → `""`, нижний регистр, «ё»→«е».
- Вход: `v` — значение. Выход: текст. Побочные эффекты: нет.

### IsStart(v) / IsEnd(v) (внутренние лямбды)
- Назначение: распознать «готов к приемке» / «готов к выбытию» по префиксу.
- Вход: `v` — значение `ready_for`. Выход: logical. Побочные эффекты: нет.
