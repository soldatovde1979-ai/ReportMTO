# qKeepWeeks

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Power Query запрос (CORE, generic), v7.3. Возвращает глубину хранения `tbDATA` в неделях (ретеншн). Источник — лист `Variable`, таблица `tblVariable`, ключ `DATA/KEEP_WEEKS`; других источников нет. Загружается ТОЛЬКО как подключение.

## Процедуры / Функции

### qKeepWeeks (запрос)
- Назначение: прочитать и вернуть число недель хранения.
- Вход: `tblVariable` (столбцы `Key`, `Value`).
- Выход: целое число недель; `0`, если ключа нет, значение пустое/мусорное или нечисловое (ретеншн выключен); значения `N < 1` приводятся к `0`.
- Побочные эффекты: чтение книги; записей нет.
