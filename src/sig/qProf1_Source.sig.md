# qProf1_Source

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Диагностический профиль конвейера `Query-ImportJSON` (шаг `Source`): возвращает число записей после чтения источника (файл или папка `*.json`). В сборку не входит, в `tbDATA` не грузится.

## Процедуры / Функции

### qProf1_Source (запрос)
- Назначение: профилирование шага `Source`.
- Вход: `prmSourcePath` — файл или папка; тело совпадает с `Query-ImportJSON` (источник читается один раз, сортировка очереди файлов по штампу из имени).
- Выход: таблица `#table({"Rows"}, ...)` с числом записей `Source`.
- Побочные эффекты: чтение JSON-файлов; записей нет.
