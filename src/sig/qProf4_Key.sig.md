# qProf4_Key

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Диагностический профиль конвейера `Query-ImportJSON` (шаг `WithKey`): число строк после добавления `Key` функцией `fnComputeKey`. В сборку не входит, в `tbDATA` не грузится.

## Процедуры / Функции

### qProf4_Key (запрос)
- Назначение: профилирование шага вычисления ключей.
- Вход: `prmSourcePath` — файл или папка.
- Выход: таблица `#table({"Rows"}, ...)` с числом строк `WithKey`.
- Побочные эффекты: чтение JSON-файлов; записей нет.
