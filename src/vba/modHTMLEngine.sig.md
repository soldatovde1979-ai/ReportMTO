# modHTMLEngine

Статус: CLEAN
Обновлено: 16.09.2026

## Назначение
Работа с HTML-шаблоном и файлами отчёта: рендер плейсхолдеров, сохранение файла, чтение/запись UTF-8, экранирование HTML.

## Процедуры / Функции

### RenderTemplate(templatePath As String, placeholders As Object) : String
- Вход: путь к шаблону HTML, словарь плейсхолдеров
- Выход: HTML с подставленными значениями
- Побочные эффекты: читает файл шаблона

### SaveHTMLFile(html As String, resultFolder As String) : String
- Вход: готовый HTML, папка результата
- Выход: полный путь сохранённого файла ("" при ошибке)
- Побочные эффекты: создаёт папку результата (если нет) и записывает файл

### ReadUtf8(path As String) : String
- Вход: путь к файлу
- Выход: содержимое в UTF-8 (BOM не учитывается)
- Побочные эффекты: читает файл

### WriteUtf8(path As String, content As String)
- Вход: путь, содержимое
- Выход: нет
- Побочные эффекты: записывает файл без BOM

### HtmlEscape(s As String) : String
- Вход: произвольная строка
- Выход: HTML-экранированная строка
- Побочные эффекты: нет побочных эффектов

### ResolveOutputFolder(raw As String) : String
- Вход: путь (возможно, относительный)
- Выход: абсолютный путь к папке вывода
- Побочные эффекты: нет побочных эффектов

### EnsureFolder(path As String) : String
- Вход: путь
- Выход: "" при ошибке создания
- Побочные эффекты: создаёт папку, если её нет
